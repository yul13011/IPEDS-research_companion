IPEDS Access Database for the 2024-25 Integrated Postsecondary Education Data (IPEDS) Collection, Provisional Release Version
The 2024-25 IPEDS Access Database contains data that were collected in the 2024-25 IPEDS data collection. The IPEDS data collection consisted of 3 collection modules:
Fall 2024: Institutional Characteristics 2024-25, Cost of attendance (COST1), 2021-22 - 2024-25,12-Month Enrollment 2023-24 and Completions 2023-24
Winter 2024-25: Admissions 2024-25, Graduation Rates 2024, Outcome Measures 2024, Student Financial Aid 2023-24 and Average net price (COST2), 2021-22 - 2023-24.
Spring 2024: Fall Enrollment 2024, Finance fiscal year 2024, Human Resources 2024-25, and Academic Libraries, fiscal year 2024.  
The cost of attendance and tuition variables that were previously collected via the Institutional Characteristics (IC) component have been moved to the new Cost (COST1) survey component. The average net price of attendance and financial aid information needed to calculate average net price that were previously collected via the SFA component have been moved to the new Cost (COST2) survey component. 
The data in the 2024-25 IPEDS Access Database are Provisional Released Data. The IPEDS Access Databases are released in two phases: provisional and final. Provisional data are released one year after collection closed and final data are released two years from when the original collection closed. During the 2025-26 collection, institutions are allowed to submit revisions to their 2024-25 submission through the 2024-25 Prior Year Revision System. The 2024-25 provisional data will then be updated with these revisions for the final release. There are some data tables and variables that institutions are not allowed to revise. These data tables and variables are documented in this Database.
In addition to the survey component data, this database also includes all Frequently Used Variables (FUV) that were derived for display on College Navigator and used in the 2024 IPEDS Data Feedback Reports. The FUV tables are the same data that are accessible using the Survey Data’s Custom Data function found on “Use The Data” portal on the IPEDS website (http://nces.ed.gov/ipeds). The IPEDS data dictionary available for Complete Data File function on Use the Data is the same metadata tables in the IPEDS Access Database. Both the IPEDS data dictionary and metadata tables describe each data table, the variable titles, descriptions, variable types and code values for all categorical variables. Selected metadata tables are also included as an excel spreadsheet IPEDS202425TablesDoc.xlsx.
Because Microsoft Access has a variable limit for each table, the item imputation status flag variables are not included in this database. The item status flag variables are associated with all continuous variables in the database and indicate for each variable what values are reported, implied, or imputed and which variables may not be applicable for an institution. IPEDS is a mandatory survey for institutions participating in Title IV federal financial aid programs and response rates are nearly 100 percent, so most variables do not contain imputed values. Survey record response status variables are included in the database.
The following data files are included in 2024-25 IPEDS Database (IPEDS_2024-25_Provisional.zip):
IPEDS202425.MDB (560mb) – This is the Microsoft Access database that contains the data tables and metadata tables.
IPEDS202425TablesDoc.xlsx – Excel workbook containing the following spreadsheets.
Metadata Tables:
Tables24 – This table lists each data table in the database by survey component. It includes table name, table title, brief description, and data year covered. It also identifies the data release (i.e., final data that has revised the provisional data or provisional, which has yet to be revised) and the date the table was released in the IPEDS “Use the data” website.
Vartable24 – This variable table lists each variable in the data table by survey component. It includes variable names, descriptions, source, data types and formats. Also, vartable24 identifies variables that were subject to revisions.
Valuesets24 – This table lists the value labels of each categorical variable in the database. 
NewVariables24 – This table lists all new variables that were added during the 2024-25 data collection.
MetaDataDefinitions – This table describes each variable found in the metadata tables (i.e., Tables24, vartable24, valuesets24, and NewVariables24).
