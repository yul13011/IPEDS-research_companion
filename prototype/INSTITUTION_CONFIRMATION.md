# Institution confirmation before analysis

October 19, 2026. Chat enters through `institution_confirmation.ask` before conversation rewriting or analytical planning. The model extracts only literal institution mentions from the original question; it cannot expand names or choose a campus. Literal substrings are checked locally. Without AI, directory/alias scanning and limited name-pattern extraction are used.

- Exact official names (including historical source-directory names) and existing UNITIDs proceed. Literal full-name matches take priority; a unique full-name match after normalizing capitalization, spacing, diacritics and punctuation can also proceed. Every substantive token and campus qualifier is retained; this is not fuzzy spelling correction. Formatting collisions still require confirmation.
- A small explicit set of established abbreviations proceeds: Yale, Harvard, Princeton, Dartmouth, UPenn, MIT, UCLA. Official names are displayed with location and UNITID.
- Every other non-exact name requires confirmation, including a single plausible match. Ambiguous shorthand such as Columbia, Cornell, Penn or University of Michigan does not automatically select a campus.
- Candidate ranking uses directory names, punctuation normalization, location tokens and spelling similarity. Ranking never selects a default. No plausible match prompts refinement using a fuller name, city/state or UNITID.
- The transcript shows one selector per unresolved mention, an optional search refinement, Continue and Cancel. Continue requires a choice for every name; Cancel runs no analysis. Only directory searches and mention extraction occur before confirmation.

Confirmed original mentions become stable UNITIDs before the conversation resolver or planner sees the request. A request-local authorization guard in `catalog.institutions` rejects model-selected institutions outside those identities. Exact identities and confirmed choices are retained in session conversation history and audit output. Follow-ups can reuse established identities; previously unconfirmed names require selection; the same confirmed normalized name reuses the session convention. New conversation clears history and pending confirmation. The extract builder already submits explicit UNITIDs and keeps its existing selection flow.

Directory lookup spans the supplied years; actual execution must still resolve the selected UNITID in every requested release. An unavailable institution/year is not replaced by another campus. Named institutional groups such as Ivy League expand to their explicit member IDs.

This is a bounded search interface, not exhaustive fuzzy matching. Users can refine the search or enter a UNITID. General name extraction and conversational continuations require AI; offline extraction remains limited.
