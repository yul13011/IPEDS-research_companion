# Source-backed definition questions

Definition requests route before institutional identity resolution, conversational statistical planning and query execution. Examples: “Define instructional staff”, “What does UNITID mean?”, “How is full-time undergraduate enrollment defined?”, and “What does SAL2023_IS.SAOUTLT mean?” Bare “what is” questions enter this route only when a supplied title, identifier, glossary heading or reviewed measure matches; school-specific statistical questions retain their normal route. Supported term comparisons explain each source term independently. Mixed definition-plus-statistical requests are not reduced to definition-only answers.

`definitions.py` retrieves variable/table definitions with AND-based concept matching, title/identifier/glossary ranking and bounded morphological variants. It reads only metadata and existing reviewed measure mappings, not annual institutional facts. Defaults to the latest loaded source release (2024–25); explicit annual table/variable scope is retained. Unsupported releases are not substituted. Multiple requested releases receive a scope clarification instead of an assumed universal or silently incomplete cross-year definition.

AI mode makes at most one passage-selection request for a standalone unfamiliar term. The model can select exact contiguous text from supplied records, not author an unsupported definition. Source excerpts are checked against the actual text sent to the model. Explicit glossary entries must be retained in full; other variable excerpts must retain the opening source definition/population scope. Source text preserves inclusions, exclusions and distinctions such as faculty designation versus instructional occupation. Unavailable or invalid selection falls back to one directly matched source excerpt, or a qualified bounded no-match response if the definition could not be established. Unknown provider usage/cost is not reported as zero.

Reviewed app measures such as admission rate use their existing named mapping, formula and supporting codebook definitions without a model call. The app labels this as a reviewed app definition, rather than attributing the app's raw-count formula or default to a universal codebook definition. Generic “graduation rate” is not automatically mapped to the app's six-year bachelor measure. Record IDs, full originals, source locations and physical/documentation issues are retained under Definitions & sources. Definition follow-ups can reuse a named term from the prior definition; ambiguous pronouns after multiple measures/terms ask which term is intended.

No external sources or institutional statistics are used. Retrieval is bounded; natural-language and exact-quotation checks do not prove exhaustive recall or arbitrary semantic correctness. The route does not promise all paraphrases, all custom labels, source-code decoding or a complete cross-year harmonization. The source may contain awkward wording or typographical errors; retained quotations are not silently rewritten.

Verification: `tests/test_definitions.py`; detailed acceptance evidence and development corrections in `../evaluations/DEFINITION_QUESTIONS_REVIEW.md`.
